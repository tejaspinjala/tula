# council
Use only when the decision is hard to undo or costs more than a day. Skip it for reversible choices. One round, no debate loops.

## Frame
Write the question in <=150 words: decision needed, constraints, options known, what "good" means. Attach brain note paths, not contents.

## Convene
Spawn council-architect, council-skeptic, council-security, council-ops, council-user in parallel with only the frame and note paths. Each returns <=120 words: position, biggest risk, evidence that would change its mind.

## Decide
Chair picks one option, states the dissent in one line per dissenter, and lists conditions that would reopen the decision. If two voices flag the same unverified assumption, resolve it with a measurement before deciding.

## Record
Hand the result to e-diagrammer (skill adr-excalidraw) so the decision, options, pros/cons and flow are saved as a note plus Excalidraw diagram. Reply to the CEO with the decision and the note path.
