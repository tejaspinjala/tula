# adr-excalidraw
Every build decision (UI chosen, pipeline, video versions, document/thumbnail flow) gets a diagram and a note, generated by one script so they stay in sync.

## Spec
Write a JSON file: title, context, decision, why[], options[{name,pros[],cons[],chosen}], flow{nodes[{id,label}],edges[{from,to,label}]}, versions[{id,label,note}] (optional), council[{voice,position}] (optional), evidence[] (file:line, test, measurement).

## Run
The generator script (`new-adr.ts --spec <spec.json>`) is not yet implemented; it arrives in a later slice. Until then, write the decision note by hand in brain/decisions/NNNN-slug.md following the spec fields above, and do not try to run a script. Once it exists it will create the note and the .excalidraw diagram and link them.

## Rules
Pros and cons come from council notes or measurements. At least two options must be listed, including the one rejected and why. Evidence is required (a future linter will fail decisions without it).
