# The Archive export is linked Markdown; private notes leave only on request and with re-auth

An **Archive export** lets a Guild Master take the Archive out of Guildhall as plain files that open in any Markdown tool. It is only trustworthy if the folder is portable, keeps facts apart from quarantined assumptions, and never leaks a private note by default.

**A folder of Markdown files.** One file per note at `<Hall name>/<file>.md`; notes with no Hall go under `Guild Master/`, private notes under `Private/<Hall name>/`. `Archive.md` at the root is the index, with separate Facts and Quarantined assumptions sections, counts. The builder is a pure function (`buildArchiveExport`): the caller reads the notes and writes the files.

**Safe names.** File and folder names strip `/ \ : * ? " < > | # ^ [ ]` and control characters, trim dots and spaces, suffix reserved Windows names (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`) with `_`, and cap at 120 characters. Collisions (case-insensitive, as on macOS and Windows) get ` (2)`, ` (3)` suffixes assigned in note-id order, so the same Archive always exports to the same paths.

**YAML front matter** carries id, hall, trust, claim, evidence, version, kind, `url` for link notes, and `tags: [quarantined]` for quarantined assumptions. Every string is emitted as a double-quoted scalar with escapes, so `:`, quotes, newlines and a leading `-` cannot change the structure. The title lives in the heading, never in the front matter.

**Links are rewritten, never invented.** `[[Title]]` (matched as `titleKey` does: trimmed, lower-cased) becomes `[[<path>#heading|alias-or-Title]]` when the target is in the export, so links resolve by path.

**Link resolution and indistinguishability.** The default export is byte-identical whether or not private notes exist, because the builder and the route never see them: the route lists non-private notes only and learns the private count from a count-only query (`countPrivate`), disclosed in the `X-Archive-Counts` header and the event, nowhere else. One parser (`parseWikiLinks`, shared with backlinks) takes each `]]` as closing the innermost `[[` before it, splits off `|alias` and then `#heading` / `#^block`, and matches the target with `titleKey`; titles may contain brackets, and a `]]` followed by more `]` also tries the target extended by them, preferring an exported title, else the bracket-balanced reading. (1) A target in the export becomes `[[<path>#heading|alias-or-Title]]`, with `|`, `[` and `]` stripped from the alias. (2) Any other target, private or missing alike, becomes plain text of exactly what the author wrote (the alias if present, else the target plus `#heading`), with every `[[` and `]]` collapsed to a single bracket so it can never form a link. We rejected scrubbing private titles out of public text (a `[withheld]` marker): it can never be complete (aliases, headings, recombined fragments, Unicode variants), it protects nothing, since a public note's body is already readable through the non-private Archive API, and the marker itself revealed that a private note with that title exists. The export reveals nothing beyond the non-private Archive read model. Nested brackets read as Obsidian does. Backlink rows (`note_links`) written before the shared parser keep their old keys until the note is next edited; the alias, heading and bracketed forms never produced backlinks before.

**Caps and the event.** An export is capped at 10,000 notes and 50 MB uncompressed; beyond that the route answers 413 `archive_too_large`. The passkey proof is spent before the caps are checked, so a 413 costs the Guild Master that re-auth. A successful export appends `archive.exported` with counts only (exported, privateIncluded, privateLeftOut), never titles or bodies.

**Private notes leave only on request and with re-auth.** The default export contains no private note; asking for them is a passkey-confirmed action, like unlocking a private Hall (ADR-0012). The number left out appears only in the response header and the event; `Archive.md` carries a constant line instead ("Private notes are not included in this export." or "Private notes are included, under Private/."), and zip entry times are pinned to the export's `now`, so the bytes depend on nothing private.

We rejected a single JSON dump (not readable or linkable outside Guildhall) and exporting quarantined assumptions as plain notes (it would blur them with facts once outside the Archive).
